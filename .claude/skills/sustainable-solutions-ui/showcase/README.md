# Showcase

Two documents that show what this skill produces, for people who want to see the
output before reading the rules.

- `index.html` — a self-contained page built entirely from the skill's tokens and
  rules. Open it in a browser. It covers the design tokens, a complete tool page
  on the mandatory skeleton, catalog cards, every component state, a schematic map
  with its table alternative, a comparison with an unsystematic page, and the
  verification status table. Light and dark mode, keyboard operable, responsive.
- `ssl-ui-design-guide.pdf` — a ten page guide. Every figure in it is a screenshot
  of `index.html`.

All data, regions, papers, DOIs and figures in both documents are synthetic and
labelled as such. They exist to show form and structure, not results.

The page uses only the token values in `../tokens/ssl-candidate.css`. If a token
changes, update it here as well so the two stay in step.

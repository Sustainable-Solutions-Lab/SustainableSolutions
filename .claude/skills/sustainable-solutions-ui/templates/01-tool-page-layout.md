## Mobile reading order
Title → scope/caveat → controls → result summary → visualization → table → download → methods → credits. Never conceal caveats, legend or credits. Use route-specific controls only after confirming shared component styles.

## Example copy (placeholder, not a factual lab claim)

**Eyebrow:** INTERACTIVE MAP AND MODEL

**H1:** Compare modeled impacts by region

**Lead:** Explore how changing a scenario affects an illustrative outcome across regions. Results are simulated and do not represent observed measurements.

**Key finding:** Under the selected *example* scenario, the illustrative index is **42 points**. This number is synthetic UI sample data only.

**How to read:** Darker shading represents a larger index. Hatched areas are missing data. Select a region to read its exact values in the results table.

**Limitations:** Demonstration data do not quantify any real-world risk; replace all values and text with verified project evidence before publishing.

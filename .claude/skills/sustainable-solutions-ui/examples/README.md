# Interactive demonstration (no external dependencies)

Open `index.html` locally in a browser. If local file restrictions affect module loading, serve the suite root with `python -m http.server 8000` and navigate to `/.claude/skills/sustainable-solutions-ui/examples/`.

This example shows: an editorial tool header, responsive controls, scenario selection, input validation, accessible chart and exact-value table, local CSV export, dark mode, a clearly fictional map mock-up, image/credit patterns, inline footnote and bibliography-like provenance. **It deliberately does not clone the live site's unknown CSS or create real environmental results.** All figures and regions are synthetic and the example masthead/footer are *illustrative*, not approved institutional branding.

React snippets are `ToolCard.tsx` and `ResearchAttribution.tsx`; adapt to the actual repository conventions and source registry.

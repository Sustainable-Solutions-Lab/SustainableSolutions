# Template — Scientific narration adjacent to a plot

**Question:** [What choice or scientific pattern does this figure address?]

**One-line answer:** [What is actually supported, with units and study boundaries.]

**What is shown:** [Observed / modeled / forecast], [geography], [period], [population and denominator], [scenario names], [baseline].

**How to read:** [marks, color, line type, thresholds, uncertainty interval, missing data treatment].

**Assumptions:** [material simplifications and model version].

**Important limitations:** [resolution, uncertainty, extrapolation, representativeness, causality].

**Source:** [data citation and release] · **Method:** [verified publication/code link] · **Export:** [data with filters and provenance].

For a figure with scientific risk, peer reviewer must explicitly confirm the label language (“risk”, “probability”, “possible”, “expected”, “observed”, “projected”) matches what the data actually measure.

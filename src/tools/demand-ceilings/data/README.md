# demand-ceilings tool data

Generated by the ai-labor research repo
(`Sustainable-Solutions-Lab/ai-labor`, `web/build_sector_data.py`, which
writes these exact files to `web/site-export/`); copy them over when the
research data updates. Current vintage: ai-labor commit `7500e72`
(2026-10-05).

- `sectors.json` — 84 final-demand BEA 2017 detail industries (>100k jobs):
  QCEW 2025 employment, long-run income elasticity of final demand
  (BEA PCE Engel slopes 1959–2025, clipped to [−0.5, 2.5]), labor intensity
  (compensation / gross output, 2017 benchmark), and physical / analytic /
  creative wage-bill task shares (OEWS May 2024 staffing × O*NET task
  weights via Dingel–Neiman teleworkability).
- `ge.json` — worker and capitalist per-capita real-income index paths from
  the project's two-group nonhomothetic CES general equilibrium
  (`src/ailabor/km_incidence.py`), per workers'-capital-share chi, plus the
  workers' base spending share and the model constants (`meta`).

The in-page model (`../model.js`) is verified in ai-labor against a Python
reference implementation (`web/test_sector_model.mjs`, 20 vectors, machine
precision); keep edits to either side in sync.

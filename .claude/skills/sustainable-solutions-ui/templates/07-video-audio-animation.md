# Template — Video, embedded talk, narrated animation

```yaml
id: "[video-id]"
title: "[meaningful title]"
description: "[what viewer learns in 1 sentence]"
source: "[approved file or embed URL]"
creator: "[name / organization]"
duration: "[HH:MM:SS]"
recorded: "[YYYY-MM-DD]"
reviewed: "[YYYY-MM-DD]"
poster: "[image asset ID]"
captionTrack: "[language, VTT URL]"
transcript: "[full text URL]"
audioDescription: "[track/link or equivalent integrated description]"
chapters: []
license: "[terms]"
credit: "[required acknowledgement]"
embedPrivacy: "[cookie/third-party policy]"
reducedMotionAlternative: "[static explainer / slides]"
```

**Acceptance:** user-initiated playback, no sound autoplay, accessible player controls, responsive 16:9 or justified ratio, captions/transcript/description, source-credit and non-embed fallback. Animated data must name frame interval and offer pause/step/static alternative.
